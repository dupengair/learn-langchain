# LangChain / LangGraph 学习笔记

# Memory
- Memory组件通过两个核心动作完成工作：
    - 存储（Save）：
      - 将每一轮的用户输入（HumanMessage）和AI输出（AIMessage）保存到指定存储介质（内存、数据库等）
    - 提取（Load）：
      - 新一轮对话时，从存储介质中提取历史对话，注入到Prompt中供LLM参考
- LCEL（LangChain Expression Language）架构
  - 通过 RunnableWithMessageHistory 结合 BaseChatMessageHistory 抽象类实现对话记忆管理，替代后续不支持的 ConversationChain

- 全量记忆：
  - 完整保存所有对话历史，适用于短对话场景
- 窗口记忆：
  - 仅保留最近N轮对话，控制Token消耗
- 摘要记忆：
  - 通过LLM生成对话摘要替代完整历史，平衡上下文连贯性与效率
